# 🔊 Text-to-Speech Application

**Text-to-Speech Application** is a web-based application that converts written text into spoken audio. Users can enter text, select an available voice, adjust speech settings, and listen to the generated speech. This application supports accessible communication and provides a simple way to convert text into audio.

## 🚀 Features

- 📝 Enter or paste text
- 🔊 Convert text into speech
- 🗣️ Select from available voices
- 🌐 Support for available languages
- ⚡ Adjust speech speed and pitch
- ▶️ Play and stop speech
- 📱 Responsive and user-friendly interface
- ♿ Improve accessibility for users who prefer audio output

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application functionality
- **Web Speech API** – Text-to-speech conversion

## ⚙️ How It Works

1. The user enters text into the application.
2. The user selects a voice and adjusts speech settings.
3. JavaScript processes the text using the browser's speech synthesis API.
4. The browser reads the text aloud.
5. The user can pause, resume, or stop playback where supported.

## 🎯 Objective

The main objective of this project is to develop a simple and accessible web application that converts written content into speech, making information easier to consume.

**Frontend Web Development Project**

This project demonstrates the use of HTML, CSS, JavaScript, and browser speech synthesis technologies.

**Note:** Browser-based speech synthesis depends on the browser and available system voices. Exporting speech as an audio file generally requires additional tools or a speech-generation service.
